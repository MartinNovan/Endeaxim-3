# Firmware for Endeaxim‑3

This folder used to contain the firmware sources for the Endeaxim‑3 printer.
They have now been moved to dedicated repositories:

| Firmware | Repository | Description |
|-----------|-------------|--------------|
| **Klipper for Endeaxim‑3** | [MartinNovan/Klipper-Endeaxim-3](https://github.com/MartinNovan/Klipper-Endeaxim-3) | Configuration for running Endeaxim‑3 with Klipper |
| **Marlin for Endeaxim‑3** | [MartinNovan/Marlin-Endeaxim-3](https://github.com/MartinNovan/Marlin-Endeaxim-3) | Marlin firmware for Endeaxim‑3 |

## Note for Users
If you were looking for firmware files, please visit the repositories above.
This repository no longer includes any binary or source firmware files — all development continues in the dedicated firmware repositories.

---
### Getting Started
1. Open the appropriate repository (Klipper or Marlin)
2. Follow the setup instructions provided there — they include details for building and flashing the firmware to your printer.
3. You can link back to this repository if you wish to reference the original Endeaxim project.
